# Checkpoint_3_-POO-
Terminal Bank: Simulador bancário em Python focado em POO. Aplica Abstração, Encapsulamento e Herança para gerenciar contas Corrente e Poupança. Apresenta polimorfismo em métodos de saque com taxas e lógica de rendimentos. Desenvolvido com arquitetura modular, separando a lógica de negócio da interface via terminal.
